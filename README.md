# Curso Flutter — Plan de curso

Sitio estático para el curso **Flutter + API REST**, diseñado para estudiantes de quinto nivel de una carrera tecnológica.

## Publicar con GitHub Pages

1. Crea un repositorio en GitHub y sube estos archivos a la rama `main`.
2. En GitHub, abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama `main` y la carpeta `/(root)`.
5. Guarda los cambios. GitHub mostrará la URL pública tras el despliegue.

No necesita proceso de compilación ni dependencias: GitHub Pages sirve `index.html` directamente.
