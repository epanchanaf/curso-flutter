1

Conceptos antes de programar

FormAgrupa campos y permite validarlos juntos.
GlobalKey<FormState>Identifica un formulario concreto y permite llamar a validate().
TextFormFieldCampo de texto con validator: devuelve un mensaje si es inválido y null si es válido.
TextEditingControllerPermite leer el texto. Se libera en dispose() para evitar recursos retenidos.
StatefulWidgetMantiene controladores y la prioridad seleccionada mientras se edita.
2

Crear la pantalla de formulario

Crea lib/features/tasks/presentation/task_form_screen.dart y pega el archivo completo. Guardar solo devuelve los datos a la lista; no afirma haber creado un registro remoto.

import 'package:flutter/material.dart';
import 'package:go_router/go_router.dart';

class TaskDraft {
  const TaskDraft(this.title, this.description, this.priority);
  final String title;
  final String description;
  final String priority;
}

class TaskFormScreen extends StatefulWidget {
  const TaskFormScreen({super.key});
  @override
  State<TaskFormScreen> createState() => _TaskFormScreenState();
}

class _TaskFormScreenState extends State<TaskFormScreen> {
  final _formKey = GlobalKey<FormState>();
  final _title = TextEditingController();
  final _description = TextEditingController();
  String _priority = 'Media';

  @override
  void dispose() {
    _title.dispose();
    _description.dispose();
    super.dispose();
  }

  void _submit() {
    if (!_formKey.currentState!.validate()) return;
    final draft = TaskDraft(
      _title.text.trim(), _description.text.trim(), _priority,
    );
    context.pop(draft);
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Nueva tarea')),
      body: Form(
        key: _formKey,
        child: ListView(
          padding: const EdgeInsets.all(16),
          children: [
            TextFormField(
              controller: _title,
              decoration: const InputDecoration(labelText: 'Título'),
              validator: (value) {
                final title = value?.trim() ?? '';
                if (title.isEmpty) return 'Escribe un título.';
                if (title.length < 3) return 'Usa al menos 3 caracteres.';
                return null;
              },
            ),
            TextFormField(
              controller: _description,
              decoration: const InputDecoration(labelText: 'Descripción'),
              maxLines: 3,
            ),
            DropdownButtonFormField<String>(
              initialValue: _priority,
              decoration: const InputDecoration(labelText: 'Prioridad'),
              items: ['Alta', 'Media', 'Baja']
                  .map((value) => DropdownMenuItem(
                        value: value, child: Text(value),
                      ))
                  .toList(),
              onChanged: (value) => setState(() => _priority = value ?? 'Media'),
            ),
            const SizedBox(height: 24),
            FilledButton(onPressed: _submit, child: const Text('Guardar')),
          ],
        ),
      ),
    );
  }
}

El borrador es un objeto temporal. context.pop(draft) entrega el resultado a la pantalla anterior; en la sesión 10 se usará para POST.

3

Declarar la ruta

En lib/app/taskflow_app.dart, importa task_form_screen.dart y agrega esta ruta a la lista routes de GoRouter, al mismo nivel que / y /task/:id.

GoRoute(
  path: '/new',
  builder: (context, state) => const TaskFormScreen(),
),

No reemplaces las rutas anteriores: el detalle debe seguir funcionando.

4

Abrir el formulario

En task_list_screen.dart, agrega floatingActionButton dentro de Scaffold, junto a appBar y body.

floatingActionButton: FloatingActionButton.extended(
  onPressed: () async {
    final draft = await context.push<TaskDraft>('/new');
    if (!context.mounted || draft == null) return;
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(content: Text('Formulario válido: ${draft.title}')),
    );
  },
  icon: const Icon(Icons.add),
  label: const Text('Nueva tarea'),
),

Agrega también import 'task_form_screen.dart';. El mensaje verifica el retorno del borrador; no representa una creación remota.
