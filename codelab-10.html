Agregar operaciones al Service

En task_api_service.dart, coloca estos métodos dentro de TaskApiService, después de getTasks. La API de práctica solo conoce title, completed y userId; descripción y prioridad siguen siendo locales.

Future<Task> createTask(String title) async {
  final response = await _dio.post<Map<String, dynamic>>(
    '/todos',
    data: {'title': title, 'completed': false, 'userId': userId},
  );
  final json = response.data;
  if (json == null) throw const FormatException('Respuesta vacía.');
  return Task.fromJson(json);
}

Future<void> updateTask(Task task) async {
  await _dio.patch(
    '/todos/${task.id}',
    data: {'title': task.title, 'completed': task.isCompleted},
  );
}

Future<void> deleteTask(int id) async {
  await _dio.delete('/todos/$id');
}

await espera la respuesta; si Dio lanza una excepción, no se debe anunciar éxito.

Agrega las tres firmas al final de TaskRepository. Luego implementa los métodos en RemoteTaskRepository. El repositorio conserva cambios locales hasta la próxima recarga; adapta también LocalTaskRepository si lo mantienes en el proyecto.

@override
Future<Task> createTask(
  String title, String description, String priority,
) async {
  final response = await _apiService.createTask(title);
  final task = Task(
    id: response.id, title: title, description: description,
    priority: priority, isCompleted: false, userId: response.userId,
  );
  _tasks = [..._tasks, task];
  return task;
}

@override
Future<void> updateTask(Task task) async {
  await _apiService.updateTask(task);
  save(task);
}

@override
Future<void> deleteTask(int id) async {
  await _apiService.deleteTask(id);
  _tasks = _tasks.where((task) => task.id != id).toList();
}

Los bloques están etiquetados por clase: pega cada grupo en el archivo correspondiente, dentro de la clase y antes de su llave final.

Mantener el Repository local compilable

Como LocalTaskRepository también implementa TaskRepository, agrega estos métodos dentro de esa clase. Conserva los cinco objetos originales y sus métodos getTasks y save.

@override
Future<Task> createTask(
  String title, String description, String priority,
) async {
  final nextId = _tasks.isEmpty ? 1 :
      _tasks.map((task) => task.id).reduce((a, b) => a > b ? a : b) + 1;
  final task = Task(
    id: nextId, title: title, description: description,
    priority: priority, isCompleted: false, userId: 1,
  );
  _tasks.add(task);
  return task;
}

@override
Future<void> updateTask(Task task) async => save(task);

@override
Future<void> deleteTask(int id) async {
  _tasks.removeWhere((task) => task.id == id);
