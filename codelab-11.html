1

Conceptos antes de programar

DioExceptionError del cliente HTTP; su tipo y response ayudan a distinguir red y servidor.
TimeoutLa conexión o respuesta tardó más del límite configurado.
4xx / 5xxRespuesta HTTP recibida: solicitud inválida o fallo del servidor.
Excepción de dominioMensaje propio del proyecto que oculta detalles técnicos a la vista.
ReintentoRepetir una acción solo cuando sea seguro; repetir POST puede duplicar una creación.
2

Crear una excepción comprensible

Crea lib/core/task_failure.dart.

class TaskFailure implements Exception {
  const TaskFailure(this.message);
  final String message;
  @override
  String toString() => message;
}

El usuario ve message; el código técnico permanece en la consola.

3

Traducir errores en Repository

En RemoteTaskRepository, importa package:dio/dio.dart y ../../../core/task_failure.dart. Envuelve la llamada de getTasks y conserva la actualización de _tasks tras una respuesta válida.

try {
  _tasks = await _apiService.getTasks();
  return List.unmodifiable(_tasks);
} on DioException catch (error) {
  if (error.type == DioExceptionType.connectionTimeout ||
      error.type == DioExceptionType.receiveTimeout) {
    throw const TaskFailure('El servidor tardó demasiado.');
  }
  if (error.response?.statusCode != null) {
    throw TaskFailure('La API respondió con HTTP ${error.response!.statusCode}.');
  }
  throw const TaskFailure('Revisa tu conexión a internet.');
} on FormatException {
  throw const TaskFailure('La API devolvió datos inesperados.');
}

La ruta relativa sube desde features/tasks/data a lib/core. No muestres error.toString() directamente en la pantalla.

4

Mostrar el mensaje y evitar envíos repetidos

En TasksViewModel.loadTasks, cambia el catch genérico por este bloque y conserva finally. Para crear, editar y eliminar, usa una bandera isSaving y deshabilita Guardar mientras sea true.

on TaskFailure catch (failure) {
  _tasks = [];
  errorMessage = failure.message;
} catch (error) {
  _tasks = [];
  errorMessage = 'Ocurrió un problema inesperado.';
  debugPrint('Error inesperado: $error');
}

Importa TaskFailure en el ViewModel. La vista de la sesión 8 ya muestra errorMessage y Reintentar.
