Conceptos antes de programar

PersistenciaConservar un dato después de cerrar la app.
Clave y valorUna clave como user_name identifica una cadena almacenada.
SharedPreferencesAsyncAPI asíncrona del paquete shared_preferences para leer y escribir preferencias pequeñas.
TokenCredencial de autenticación. Si una API real lo requiere, necesita almacenamiento seguro; aquí no se usa.

3

Crear el servicio de preferencias

Crea lib/core/user_preferences.dart.

import 'package:shared_preferences/shared_preferences.dart';

class UserPreferences {
  UserPreferences(this._preferences);
  final SharedPreferencesAsync _preferences;
  static const _nameKey = 'user_name';

  Future<String> readName() async =>
      await _preferences.getString(_nameKey) ?? 'Estudiante';

  Future<void> saveName(String name) async {
    await _preferences.setString(_nameKey, name.trim());
  }
}

?? proporciona el nombre inicial si todavía no hay nada guardado.

4

Crear una pantalla de configuración

Crea lib/core/settings_screen.dart.

import 'package:flutter/material.dart';
import 'user_preferences.dart';

class SettingsScreen extends StatefulWidget {
  const SettingsScreen({super.key, required this.preferences});
  final UserPreferences preferences;
  @override
  State<SettingsScreen> createState() => _SettingsScreenState();
}

class _SettingsScreenState extends State<SettingsScreen> {
  final _controller = TextEditingController();
  bool _loading = true;
  @override
  void initState() {
    super.initState();
    _load();
  }
  Future<void> _load() async {
    final name = await widget.preferences.readName();
    if (!mounted) return;
    setState(() { _controller.text = name; _loading = false; });
  }
  @override
  void dispose() { _controller.dispose(); super.dispose(); }
  Future<void> _save() async {
    final name = _controller.text.trim();
    if (name.isEmpty) return;
    await widget.preferences.saveName(name);
    if (!mounted) return;
    ScaffoldMessenger.of(context).showSnackBar(
      const SnackBar(content: Text('Nombre guardado')),
    );
  }
  @override
  Widget build(BuildContext context) => Scaffold(
    appBar: AppBar(title: const Text('Configuración')),
    body: _loading ? const Center(child: CircularProgressIndicator())
      : Padding(padding: const EdgeInsets.all(16), child: Column(children: [
          TextField(controller: _controller,
            decoration: const InputDecoration(labelText: 'Tu nombre')),
          const SizedBox(height: 16),
          FilledButton(onPressed: _save, child: const Text('Guardar')),
        ])),
  );
}

mounted comprueba que la pantalla siga visible después de esperar una operación asíncrona.

5

Agregar acceso a configuración

En taskflow_app.dart, importa SettingsScreen, UserPreferences y SharedPreferencesAsync. Agrega una ruta /settings. En la lista, añade un botón de configuración a AppBar.actions.

GoRoute(
  path: '/settings',
  builder: (context, state) => SettingsScreen(
    preferences: UserPreferences(SharedPreferencesAsync()),
  ),
),

En task_list_screen.dart, agrega este botón al arreglo actions del AppBar, después del botón Actualizar. Conserva las rutas existentes.

IconButton(
  tooltip: 'Configuración',
  onPressed: () => context.push('/settings'),
  icon: const Icon(Icons.settings),
),

La ruta abre una pantalla independiente; la lista remota y el detalle siguen disponibles.
