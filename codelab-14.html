Agregar estado de búsqueda al ViewModel

Dentro de TasksViewModel, agrega estos campos y métodos. No reemplaces tasks, loadTasks ni toggleCompleted.

String query = '';
bool onlyPending = false;

List<Task> get visibleTasks => tasks.where((task) {
  final matchesText = task.title.toLowerCase()
      .contains(query.trim().toLowerCase());
  final matchesState = !onlyPending || !task.isCompleted;
  return matchesText && matchesState;
}).toList();

void setQuery(String value) { query = value; notifyListeners(); }
void setOnlyPending(bool value) {
  onlyPending = value; notifyListeners();
}
void clearFilters() {
  query = ''; onlyPending = false; notifyListeners();
}

La comparación usa la lista original. notifyListeners actualiza la vista sin consultar de nuevo la API.

3

Crear controles que conservan el texto

Crea lib/features/tasks/presentation/task_search_controls.dart y pega el archivo completo. El controlador vive en un StatefulWidget; así el cursor no pierde el foco cuando el ViewModel avisa un cambio. El botón Limpiar borra tanto el campo visible como los filtros.

import 'package:flutter/material.dart';
import 'package:provider/provider.dart';
import 'tasks_view_model.dart';

class TaskSearchControls extends StatefulWidget {
  const TaskSearchControls({super.key});
  @override
  State<TaskSearchControls> createState() => _TaskSearchControlsState();
}

class _TaskSearchControlsState extends State<TaskSearchControls> {
  late final TextEditingController _search;
  @override
  void initState() {
    super.initState();
    _search = TextEditingController(
      text: context.read<TasksViewModel>().query,
    );
  }
  @override
  void dispose() { _search.dispose(); super.dispose(); }

  @override
  Widget build(BuildContext context) {
    final model = context.watch<TasksViewModel>();
    return Padding(
      padding: const EdgeInsets.all(16),
      child: Column(children: [
        TextField(
          controller: _search,
          decoration: const InputDecoration(
            labelText: 'Buscar por título',
            prefixIcon: Icon(Icons.search),
          ),
          onChanged: context.read<TasksViewModel>().setQuery,
        ),
        SwitchListTile(
          title: const Text('Solo pendientes'),
          value: model.onlyPending,
          onChanged: context.read<TasksViewModel>().setOnlyPending,
        ),
        TextButton(
          onPressed: () {
            _search.clear();
            context.read<TasksViewModel>().clearFilters();
          },
          child: const Text('Limpiar filtros'),
        ),
      ]),
    );
  }
}

dispose libera el controlador cuando la pantalla deja de existir. El texto se conserva durante las reconstrucciones normales.

Mostrar resultados o cero coincidencias

En task_list_screen.dart, importa task_search_controls.dart. Dentro de _buildBody, conserva sin cambios las ramas de carga, error y lista remota vacía de la sesión 8. Reemplaza solo el return RefreshIndicator(...) final por este bloque completo:

return Column(
  children: [
    const TaskSearchControls(),
    if (viewModel.visibleTasks.isEmpty)
      const Expanded(
        child: Center(
          child: Text('No hay resultados para estos filtros.'),
        ),
      )
    else
      Expanded(
        child: RefreshIndicator(
          onRefresh: () => context.read<TasksViewModel>().loadTasks(),
          child: ListView.builder(
            physics: const AlwaysScrollableScrollPhysics(),
            padding: const EdgeInsets.all(16),
            itemCount: viewModel.visibleTasks.length,
            itemBuilder: (context, index) {
              final task = viewModel.visibleTasks[index];
              return Card(
                child: ListTile(
                  leading: Icon(task.isCompleted
                      ? Icons.check_circle
                      : Icons.radio_button_unchecked),
                  title: Text(task.title),
                  subtitle: Text('Prioridad: ${task.priority}'),
                  trailing: const Icon(Icons.chevron_right),
                  onTap: () => context.push('/task/${task.id}'),
                ),
              );
            },
          ),
        ),
      ),
  ],
);

Expanded da espacio acotado a la lista desplazable. Cero coincidencias después de filtrar es distinto del estado vacío de la API. Usa Limpiar filtros para recuperar todas las tareas ya cargadas.
